# Code of Conduct

We want this project to be a friendly, harassment-free space for everyone.

**Expected:** be respectful, welcome different experience levels, give and accept constructive feedback, focus on what is best for the project.

**Not acceptable:** harassment, insults, discriminatory language, personal attacks, publishing someone's private information, or any conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, issues or contributions that break these rules and may block repeat offenders. To report a problem, use GitHub's "Report content" or contact the maintainers privately through the repository's security contact.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
